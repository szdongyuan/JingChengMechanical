# 主页“录制异常数”文案调整设计

## 目标

将主页今日统计区域的标签“异常数：”调整为“录制异常数：”，让该数字的含义更明确。

## 范围

- 仅修改 `ui/modules/today_statistics.py` 中主页今日统计区域对应的静态标签。
- 保留现有数值来源、刷新机制、颜色、控件位置及布局配置。
- 不修改其他页面中可能出现的相似文案。

## 设计

在 `TodayStatisticsModule.__init__` 中，将 `QLabel("异常数：")` 改为 `QLabel("录制异常数：")`。不新增抽象或资源文件，因为该文案当前仅在此处使用，直接修改符合现有实现模式。

## 验收标准

1. 主页今日统计区域显示“录制异常数：”。
2. 项目中原主页标签“异常数：”不再存在。
3. 异常计数的计算和展示逻辑保持不变。
4. 其他页面和功能不受影响。

## 验证

- 运行针对该模块的静态文案检查或相关测试，确认新文案存在且旧文案不存在。
- 检查最终差异，确认产品代码只发生一处静态字符串替换。
