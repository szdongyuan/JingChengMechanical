# 历史分析结果回放与重新标记

## 已批准的产品范围

数据管理每条记录增加「查看分析结果」按钮，打开独立、非模态的历史分析结果窗口。窗口提供已保存分析结果、录音试听及重新标记，不修改分析参数、不提交重新分析、不改变实时测试界面。用户已批准这一设计，并要求计划审查后直接实施；不再重复请求实施许可。

## 方案及边界

采用独立历史窗口，复用现有结果/图表组件和音频回放能力。相较于切换实时测试页，此方案不会替换当前测试上下文；相较于另造整套图表，复用组件能保持已有显示风格与语义。现有数据管理的回放入口保留。

### 结果读取

- 以持久化 run_id 定位记录，不依赖本次启动的内存历史列表。
- 展示 SN、型号、配置名称、记录时间、当前判定/判定来源及故障类型；读取该记录最新成功分析的已保存结果与冻结配置。若存在后来失败的分析尝试，不把它当成成功结果。
- 展示已有声压级、响度、频谱得分、AI 结果和配置对应图表（包括保存的振动图表）。复用现有结果组件及其布局规则，不另行改变实时结果页。
- 原始分析判定与当前人工标记应区分：重新标记不得重写已保存的 AI、测量值、分析判定或图表。
- 原始结果、音频分别可用：缺少音频不阻止查看结果和标记；缺少分析结果不阻止查看记录信息、可用音频和标记。缺失部分提示「未保存/不可用」，禁止静默重新分析、使用当前配置补算或使用其他记录的数据。
- 已保存的轻量结果可展示现有数值，图表为空时明确提示尚无已保存图表。窗口提供刷新以重新读取后来保存的完整结果；不为此启动新的分析。
- 数据读取/大结果解压及音频图形准备避免在 GUI 线程长时间阻塞；窗口先显示加载状态。关闭或刷新后，旧加载完成不得覆盖新的窗口状态。

### 试听

- 窗口内提供完整录音/框选时间段播放、停止、通道选择和播放增益，复用 run-scoped playback，沿用当前设备与并发限制，不重新打开录音输入设备。
- 试听范围、通道和增益只影响试听。试听波形/频谱可从音频生成，并明确属于试听视图，不替换保存的分析图表。
- 离开/关闭该回放窗口时停止它发起且仍归它所有的播放，不能停止其他窗口后来发起的播放。保留现有 playback 服务约束，不重构音频后端。
- 音频不可用时禁用试听并提示，但其他功能保持可用。

### 重新标记

- 复用 RunDataManagementService.update_fault_type 与现有记录冻结配置允许的选项：合格对应 PASS；故障类型对应 FAIL；没有配置故障类型的记录沿用现有不合格规则。
- 提供明确「保存标记」操作。成功后显示持久化的当前判定、人工来源及故障类型，并刷新数据管理列表；失败时提示，保留此前已提交值，不假报成功。
- 只更新该 run 的人工判定字段；不修改分析结果文件、音频、配置，不触发 PLC、重新分析或录音。活动记录不能标记，沿用现有服务限制。

### 窗口与隔离

- 同一条记录重复点击聚焦已有历史窗口，关闭后可重新打开。可查看不同记录，但每个窗口绑定自己的 run_id。
- 保存标记、刷新和迟到加载都必须作用于所属记录。实时录音/结果信号不覆盖历史窗口；历史窗口不写实时控制器状态。
- 数据管理现有筛选、分页、导出、删除和回放保持兼容。打开后记录被删除，再刷新/保存时明确提示记录不可用；不要求额外的删除锁或完整审计系统。

## Compatibility / Migration

- Backward compatibility: required
- Protected surfaces: 现有数据库结构与记录、音频/结果文件格式、录音与 PLC 行为、实时结果页组件及布局、数据管理原有操作。
- Allowed breakage: none；仅新增按钮和独立历史窗口。
- Migration strategy: none。复用现有表、成功分析结果解析/解压和人工标记写入；不补写旧结果。

## 验证与验收

1. 使用持久化记录（不放入实时历史缓存）打开对应结果；验证数值、AI、图表、配置来自该记录最新成功结果。
2. 使用不同内容的 A/B 记录验证窗口互不串数据；实时结果更新不覆盖历史窗口；关闭/刷新期间迟到工作结果不误投递。
3. 标记合格/故障后重读数据库，验证人工字段更新、列表与窗口更新，原始结果文件与音频未改动；写入失败有提示。
4. 有结果无音频、有音频无结果、缺图表、记录被删除均能显示真实可用内容和相应提示。
5. 试听请求携带正确 run_id、物理通道、范围和增益，停止/关闭不终止另一窗口接管的播放；不调用录音和重新分析接口。
6. 重复打开/关闭和异步加载期间关闭无运行中 QThread 销毁；复用已有组件做 Qt 离屏视觉检查。
7. 回归数据管理、相关结果组件、历史持久化/播放测试。已知基线无关失败单独记录，不扩展到无关修复。

不承诺新增绝对加载时限；沿用已有实时录音与结果性能约束，历史读取不占用分析调度队列。
