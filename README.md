# 智能电机检测 - 声学检测系统

> 开发计划与进度追踪见 [Roadmap Issue](../../issues/1)

## 已完成

### 应用框架
- PyQt6 主窗口与标签页导航（测试 / 数据管理 / 配置 / 硬件）
- 事件总线模块间通信（EventBus 信号机制）
- 全局样式与状态栏
- 日志系统（滚动文件日志 + UI 日志面板）
- SQLite 数据库 ORM（Peewee）与自动建表

### 硬件选择
- 声卡设备枚举（支持 ASIO）
- 输入 / 监听设备选择与持久化
- Host API 分组显示
- 设备变更通知其他模块

### 输入校准
- 标准声压级选择（94 dB / 114 dB）
- 通道选择与录音
- 平均声压级计算与偏差显示

### 测试配置管理
- 配置 CRUD（新建 / 删除 / 列表 / 加载）
- 全局参数编辑（采样率、分析时长、录音时长等）
- 按通道独立配置（STFT、SPL、FFT 频段限值、1/3 倍频程限值）
- 折叠分组面板
- 输入校验与约束（上下限联动、浮点数限制）
- 配置持久化到数据库

### 测试页面布局
- 工单输入面板
- 测试控制面板（启动 / 停止 / 手动判定）
- 结果展示面板（PASS/FAIL、AI 评分、SPL 值）
- 分析图表占位（频谱 / STFT / SPL / 倍频程）
- 视频画面占位
- 模拟测试流程（TestService demo）
